JoyaControl no arrancó en esta vista

Estás viendo una vista previa: muestra el archivo, pero no ejecuta el programa que tiene dentro. Pasa con la vista previa de WhatsApp o del correo, con la vista rápida del Mac y con el visor de archivos de Claude.

Cómo abrirlo bien:

  1. Guarda el archivo joyacontrol.html en tu computador, por ejemplo en Descargas o en el Escritorio.
  2. Ábrelo con un navegador: clic derecho sobre el archivo → «Abrir con» → Chrome, Edge, Safari o Firefox.
  3. Si ves la pantalla de Inicio con cifras y la guía de prueba, ya está funcionando.

Úsalo en un computador. En el celular, las vistas previas no lo ejecutan.

JoyaControl did not start in this view

You are looking at a preview: it shows the file but does not run the program inside it. This happens with WhatsApp or email previews, Quick Look on the Mac and Claude's file viewer.

How to open it properly:

  1. Save the file joyacontrol.html on your computer, for example in Downloads or on the Desktop.
  2. Open it with a browser: right-click the file → "Open with" → Chrome, Edge, Safari or Firefox.
  3. If you see the Home screen with figures and the test guide, it is working.

Use it on a computer. On a phone, previews do not run it.
